# 🛍️ TechStore - Магазин Техники

Современный и стильный интернет-магазин техники с потрясающими визуальными эффектами, анимациями и свечением!



## ✨ Особенности

- 🎨 **Современный дизайн** - Градиенты, неоновые эффекты и стеклянные элементы
- ✨ **Анимации и свечение** - Все элементы мигают, светятся и плавно анимируются
- 📱 **Адаптивный дизайн** - Отлично работает на всех устройствах (десктоп, планшет, мобильный)
- 🎯 **Интерактивность** - Плавные переходы и эффекты при наведении курсора
- 📚 **Подробные комментарии** - Каждая строка кода прокомментирована на русском языке для обучения

## 🚀 Технологии

- **HTML5** - Семантическая разметка
- **CSS3** - Стили, анимации, градиенты, эффекты свечения
- **CSS Grid & Flexbox** - Современная верстка
- **CSS Animations** - Плавные анимации и переходы
- **Responsive Design** - Адаптация под разные экраны

## 🎯 Функциональность

### Секции сайта:

1. **Шапка (Header)**
   - Логотип с градиентным текстом и анимацией свечения
   - Навигационное меню с эффектами при наведении
   - Липкая шапка (остается наверху при прокрутке)

2. **Главная секция (Hero)**
   - Приветственный баннер с анимированным заголовком
   - Плавающие декоративные элементы
   - Кнопка призыва к действию с эффектом свечения

3. **Каталог товаров (Products)**
   - Сетка с карточками товаров
   - Анимированные карточки с эффектами при наведении
   - Бейджи: "Новинка", "Хит", "Скидка"
   - Цены с пульсирующим свечением
   - Кнопки покупки с градиентным фоном

4. **О нас (About)**
   - Информация о магазине
   - Особенности с анимированными иконками
   - Эффекты при наведении

5. **Контакты (Contact)**
   - Информация для связи
   - Анимированные иконки
   - Интерактивные карточки контактов

6. **Подвал (Footer)**
   - Информация о копирайте
   - Свечение по верхней границе

## 🎨 Визуальные эффекты

### Анимации:
- ✨ **Glow эффекты** - Свечение текста, кнопок и элементов
- 💫 **Pulse** - Пульсирующие элементы (мигание)
- 🌊 **Float** - Плавающие декоративные фигуры
- 🎯 **Bounce** - Подпрыгивающие иконки товаров
- 🔄 **Rotate** - Вращающиеся иконки
- ✨ **Shine** - Блики на карточках товаров

### Цветовая схема:
- 🔵 **Cyan** (#00ffff) - Основной акцентный цвет
- 🟣 **Magenta** (#ff00ff) - Вторичный акцент
- 🟡 **Yellow** (#ffff00) - Для цен
- ⚫ **Dark** (#0a0a0a, #1a1a2e) - Темный фон

## 🌟 Особенности реализации

### CSS Grid для товаров:
```css
.products-grid {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(300px, 1fr));
    gap: 30px;
}
```
Автоматически создает колонки, адаптируясь под размер экрана.

### Анимация свечения:
```css
@keyframes glow-text {
    0%, 100% { text-shadow: 0 0 20px rgba(0, 255, 255, 0.5); }
    50% { text-shadow: 0 0 40px rgba(0, 255, 255, 1); }
}
```
Создает эффект пульсирующего свечения.

### Градиентный текст:
```css
background: linear-gradient(45deg, #00ffff, #ff00ff);
-webkit-background-clip: text;
-webkit-text-fill-color: transparent;
```
Делает текст с градиентной заливкой.

## 🎨 Кастомизация

### Изменить цвета:
Найдите в CSS все вхождения цветов и замените:
- `#00ffff` - основной цвет (cyan)
- `#ff00ff` - вторичный цвет (magenta)
- `#ffff00` - цвет для цен (yellow)

### Изменить скорость анимаций:
Измените значение в свойстве `animation`:
```css
animation: glow-text 3s ease-in-out infinite;
/* 3s - длительность, измените на нужное значение */
```

### Добавить новые товары:
Скопируйте блок `.product-card` в HTML и измените данные.
